# TanTanTzy Portfolio

A complete responsive portfolio website built around your current projects:

- LaunchBoard
- StudyNest

## Included

- Landing page
- Featured projects
- About section
- Skills section
- Contact form
- Résumé page
- Mobile-responsive design

## Before publishing

Open `index.html` and replace:

- `your-email@example.com`
- project links if your live URLs change
- any wording you want to personalize

## Publish

Upload all files to a GitHub repository and enable GitHub Pages.

Suggested repository name:

`portfolio`

Suggested URL:

`https://tantantzy.github.io/portfolio/`
